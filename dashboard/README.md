# Cafe Sales Dashboard

Open [`index.html`](index.html) in a browser for a concise visual overview of the Excel analysis. The [`Cafe_Sales_Data_Analysis.xlsx`](Cafe_Sales_Data_Analysis.xlsx) file is the full workbook (11 worksheets). The [`raw_data.csv`](raw_data.csv) file is the uncleaned contents of the workbook's `1_Raw_Data` sheet (1,836 records, 11 columns). GitHub can display it as a table.

The workbook uses simulated 2025 point-of-sale data for four branches. Its headline net-revenue figure is ₱394,428; it is not a real business result.

The raw CSV intentionally retains the source sheet's data-quality issues, including duplicates and inconsistent entries; it has not been cleaned. All records are simulated, not actual customer or business data.
