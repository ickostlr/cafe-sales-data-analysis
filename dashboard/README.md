# Cafe Sales Dashboard

Open [index.html](index.html) in a browser for a concise visual overview of the Excel analysis. Use the link in the dashboard to open the full workbook, which contains all 11 worksheets, the analysis tables, eight charts, evidence-backed findings, and prioritized recommendations.

The workbook uses simulated 2025 point-of-sale data for four branches. Its headline net-revenue figure is PHP 394,428; it is not a real business result.
